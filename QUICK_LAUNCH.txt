                    LLAMA 3 - QUICK LAUNCH GUIDE

NEED HELP LAUNCHING THIS APP?
Just run this command and follow the prompts:

    python3 launch_helper.py

That's it! The helper will:
  ✓ Check your Python installation
  ✓ Check if dependencies are installed
  ✓ Help you install what's missing
  ✓ Check if the model is downloaded
  ✓ Guide you through any issues
  ✓ Launch your app when ready

================================================================================
FIRST TIME SETUP (One Time Only)
================================================================================

1. Install Dependencies:
   
   pip install -e .

2. Download Model:
   
   a. Visit: https://llama.meta.com/llama-downloads/
   b. Register and accept license
   c. You'll get a download URL via email
   d. Run: ./download.sh
   e. Paste the URL when prompted

================================================================================
LAUNCH OPTIONS
================================================================================

Option 1: Interactive Helper (RECOMMENDED for first time)
   
   python3 launch_helper.py
   
   Best for: First time users, troubleshooting, checking setup

Option 2: Quick Launcher Menu (for regular use)
   
   ./launch_app.sh
   
   Best for: After setup is complete, quick app selection

Option 3: Direct Command (for advanced users)
   
   torchrun --nproc_per_node 1 my_first_app.py \
       --ckpt_dir Meta-Llama-3-8B-Instruct/ \
       --tokenizer_path Meta-Llama-3-8B-Instruct/tokenizer.model
   
   Best for: Automation, scripts, experienced users

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "python3: command not found"
Solution: Install Python 3.8+ from python.org

Problem: "Module 'llama' not found"
Solution: Run: pip install -e .

Problem: "Model directory not found"
Solution: Follow setup step 2 above to download model

Problem: "Out of memory"
Solution: Close other apps, use smaller parameters, or upgrade RAM

Problem: "Permission denied: ./launch_app.sh"
Solution: Run: chmod +x launch_app.sh
